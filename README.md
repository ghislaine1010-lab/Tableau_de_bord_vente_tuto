# Tableau de bord dynamique des ventes avec Excel

## Présentation du projet

Ce projet consiste à concevoir un tableau de bord dynamique permettant d’analyser les ventes et de faciliter la prise de décision à partir d’un jeu de données initialement regroupé dans une seule table, appelée **Commande**.

L’objectif était de restructurer, nettoyer et exploiter les données afin de construire un modèle de données cohérent et de produire des indicateurs pertinents pour le suivi des performances commerciales.

## Objectifs du projet

- Restructurer les données initiales pour faciliter leur exploitation.
- Améliorer la qualité et la fiabilité des données.
- Construire un modèle de données relationnel.
- Calculer les indicateurs clés de performance (KPI).
- Concevoir un tableau de bord interactif pour faciliter l’analyse des ventes et la prise de décision.

## Démarche et méthodologie

### 1. Restructuration des données

La table initiale **Commande** a été répartie en quatre tables distinctes :

- **Clients** : informations relatives aux clients.
- **Produits** : informations sur les produits commercialisés.
- **Ventes** : informations relatives aux commandes et aux transactions.
- **Régions** : informations géographiques permettant d’analyser les performances commerciales par région.

Cette organisation permet de mieux structurer les données et de limiter les redondances.

### 2. Nettoyage et transformation avec Power Query

Un travail de préparation des données a été effectué afin d'améliorer leur qualité et de les rendre exploitables :

- Détection et suppression des doublons.
- Identification et traitement des valeurs manquantes.
- Vérification et correction des types de données.
- Contrôle des incohérences dans les données.
- Création de colonnes calculées nécessaires aux analyses.
- Préparation des tables pour leur intégration dans le modèle de données.

### 3. Modélisation avec Power Pivot

Les différentes tables ont ensuite été intégrées dans Power Pivot afin de construire un modèle de données relationnel.

Cette étape a consisté à :

- Établir les relations entre les tables Clients, Produits, Ventes et Régions.
- Organiser les données pour permettre des analyses croisées.
- Créer les indicateurs clés de performance nécessaires au suivi des ventes.

### 4. Analyse et visualisation avec Excel

À partir du modèle de données, des tableaux croisés dynamiques et des graphiques ont été créés pour analyser les performances commerciales.

Ces éléments ont ensuite été regroupés dans un tableau de bord dynamique, conçu pour faciliter la consultation des indicateurs et l'exploration des données selon les dimensions d'analyse disponibles.

## Outils et technologies utilisés

- **Microsoft Excel** : création des tableaux croisés dynamiques, des graphiques et du tableau de bord.
- **Power Query** : nettoyage, transformation et préparation des données.
- **Power Pivot** : modélisation relationnelle et création des indicateurs de performance.

## Résultat obtenu

Le projet a abouti à la création d’un **tableau de bord dynamique des ventes** permettant de centraliser les principaux indicateurs commerciaux et de faciliter l’analyse des performances.

Cette solution contribue à rendre les données plus accessibles, à identifier les tendances commerciales et à soutenir une prise de décision fondée sur les données.

## Compétences développées

- Préparation et nettoyage des données.
- Transformation et structuration des données avec Power Query.
- Modélisation de données avec Power Pivot.
- Création d’indicateurs clés de performance.
- Analyse des ventes avec les tableaux croisés dynamiques.
- Visualisation des données et conception de tableaux de bord.
- Exploitation des données à des fins d’aide à la décision.
